
# Freelance Landing Page

A simple and lightweight HTML/CSS landing page for freelance web developers.

## Features

- Responsive design
- Clean and modern UI
- Easy to deploy to GitHub Pages or Netlify

## Usage

1. Clone the repo or download the ZIP.
2. Open `index.html` in your browser or deploy to any static hosting service.
3. Update the contact email if needed.
